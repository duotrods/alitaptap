# TapCard

A mobile-first NFC ordering demo for small food businesses.

## Run locally

```bash
npm install
npm run dev
```

Demo routes:

- `/` — product landing page
- `/order/kape-ni-juan?table=T01` — customer menu and cart
- `/login` — staff sign-in
- `/dashboard/orders` — interactive staff order board

Demo staff credentials:

- Email: `staff@kapenijuan.ph`

## Data

This first frontend prototype uses local mock data only. It does not include a database client, schema, migration, credentials, or remote persistence.
